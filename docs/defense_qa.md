# Вопросы к защите и ответы

Самые неудобные вопросы, которые получила независимая проверка проекта, и ответы с опорой на артефакты. Числа — seed 0, размеченные алерты, 95% интервал Уилсона.

**1. Метки соседей того же шага в момент решения неизвестны. Как тогда работает красный флаг?**
Никак: в реальном времени его не посчитать, поэтому в v2 он перенесён в ретроспективный аудит регулятора. В момент решения аналитику доступны два сигнала без таких меток:
- C2 «контрфактуал ≤ 3 потоков»: precision 0,33 [0,29; 0,38] при базе 0,66;
- сигналы М6 (флаг без потоков; прецеденты из шагов 1–29).

**2. C1 проходят только шаги 35, 38 и 42. С какой базой сравнивается протокол?**
С базой этих же шагов: 0,78 [0,74; 0,81], n = 558. Годные по v1 — 0,52, строгий v1 — 0,72, годные по v2 — 0,87 [0,75; 0,94]. Ни одна группа не лучше базы надёжно, а v1 — хуже (`m11_precision_ci.csv`).

**3. Агрегаты — это тоже информация о соседях. Почему «на признаках транзакции»?**
Потому что агрегаты — часть признаков самой транзакции в наборе данных, а не рёбра графа модели. Утверждается только одно: верные алерты не зависят от *графового канала* GCN, то есть флаг держится при нулевых весах всех потоков. По М2 у верных алертов доли такие: локальные 0,28, агрегаты 0,33, граф 0,36. У ложных: 0,22 / 0,26 / 0,47.

**4. IG с baseline w = 0 и тест удаления с w = 0 — одно и то же возмущение. Не круговая ли проверка?**
Отчасти да, и это сказано в отчёте. Независимые проверки такие:
- M-4: поток *добавляется*, внедрённое ребро попадает в top-3 в 98% случаев;
- M-6: рандомизация модели, Спирмен 0,09 и −0,06;
- порядок «по степени соседа» не лучше случайного, то есть удаление само по себе не даёт эффекта.

**5. Жаккар 0,50 ровно на пороге. Почему критерий «выполнен»?**
Он не выполнен уверенно: медиана 0,50, интервал [0,45; 0,56], не ниже 0,5 — у 51% алертов с |E_v| > 10. Поэтому в v2 устойчивость проверяется по вердикту протокола (C4: ≥ 3 из 5 сидов), а не по совпадению top-5.

**6. Голосование kNN совпадает с GCN на 90% узлов — что это доказывает?**
Ничего: 91% этих узлов licit. Среди алертов совпадение лишь 49%. Ценность М3 в другом: большинство прецедентов illicit у 71% верных алертов и только у 26% ложных (`m8_alerts.csv`).

**7. RF лучше GCN — значит, граф не нужен?**
Нет. Той же GCN граф помогает: без рёбер PR-AUC 0,60, с рёбрами 0,72 (шаги 35–42). Но RF на одних признаках даёт 0,90 (`ablation_no_edges.csv`).

**8. F1 0,70 против 0,705 у Weber — честное сравнение?**
Нет, и в отчёте оно исправлено. У Weber 0,705 на всём тесте, у нас там 0,58. Причины: обучение на шагах 1–29 вместо 1–34 и порог под precision 0,8 на валидации. 0,70 — только шаги 35–42.

**9. Аналитик видит top-5 по |IG|, а проверялся порядок по знаку?**
В v2 карточка показывает top-5 по IG со знаком — тот же порядок, который проверяли M-1…M-3.

**10. Камуфляж без пересчёта 72 агрегатов — насколько завышено «33% флагов снято»?**
Завышено. Агрегаты сдвинулись бы вместе с рёбрами, а пересчитать их нельзя: формулы агрегатов анонимизированы. Поэтому числа — верхняя оценка уязвимости графового канала, а не всей модели.

**11. Сколько ложных срабатываний у сигнала камуфляжа?**
Он срабатывает у 5,3% транзакций без флага (шаги 35–42). Illicit среди них 0,21 [0,17; 0,24] против базы 0,03; находит 97 из 239 пропущенных отмывателей (`camouflage_signal.csv`). Как вторая очередь — работает.

**12. v2 подобран на тех же данных. Почему не честное разбиение по шагам?**
Потому что C1 выполняется лишь на трёх шагах, и при разбиении на группы шагов годных останется по десятку алертов. Ответ — честно назвать числа v2 оптимистичными. Главный вывод держится на v1, пороги которого объявлены до расчёта.

**13. Б.3: precision 0,71 → 0,67 при n = 17 и 36 — это шум?**
Да, интервалы [0,47; 0,87] и [0,50; 0,80] перекрываются. Утверждается только рост доли годных обоснований: 4,3% [2,7; 6,7] → 9,0% [6,6; 12,2]. При всех пяти сидах годны 6 алертов из 400.

**14. Где обещанный перебор baseline в Б.3?**
К протоколу М5 он неприменим: М5 не использует М2, а baseline рёбер ($w = 0$) задан определением М1. Отклонение записано в README (п. 11).

**15. Медиана |E_v| = 5. Не тривиальны ли метрики у половины алертов?**
Fid− тривиальна, она так и помечена. Fid+, AOPC и Жаккар показаны отдельно для |E_v| > 10 (618 алертов): AOPC минус случайный порядок +2,33 [2,15; 2,54]; Жаккар 0,50, на пороге.

**Если спросят главное одной фразой:** объяснение верно модели, но модель находит отмывателей по признакам транзакции, а ложные алерты — по связям. Поэтому объяснение по потокам описывает «виновность по связи», а не вину, и обоснованием блокировки быть не может.
